# Support — NLP Trainer

For support with the public NLP Trainer ChatGPT plugin, please open an issue in this repository:

https://github.com/BlackStormUA/nlptrainer/issues

Please include:
- a short description of the problem;
- the prompt or workflow you were using;
- what you expected to happen;
- what happened instead;
- screenshots only if they do not expose sensitive personal information.

Do not post passwords, access codes, API keys, payment details, medical records, or other sensitive personal information in public issues.
