# Privacy Policy — NLP Trainer

Effective date: 21 October 2026

NLP Trainer is an educational ChatGPT plugin published by Oleg Novikov.

## Data processed
The plugin is designed as a skills-only educational plugin. It does not operate its own external server or database and does not independently collect account credentials, payment information, health records, or persistent user profiles.

User messages and plugin responses are processed within ChatGPT according to OpenAI's applicable terms and privacy practices.

## Personal information
Users should avoid sharing unnecessary sensitive personal information. The public plugin does not require names, dates of birth, passwords, access codes, payment details, medical records, or private third-party profiles to provide its educational functionality.

## Storage and retention
The plugin package itself does not provide external persistent storage. It does not maintain a separate customer database or interaction log outside ChatGPT.

## Third parties
The public skills-only version does not send user content to a third-party MCP server or payment provider.

## Use of information
Information supplied in a conversation is used only to respond to the user's request, adapt educational explanations, and provide exercises or feedback within the current ChatGPT interaction and any ChatGPT features the user has enabled.

## Children's privacy
The plugin is intended for general educational use. Users should follow ChatGPT age and account requirements.

## Changes
This policy may be updated when the plugin's functionality or data practices change.
